Shell version loading

Shared structure without template migrations

Applications vendor a pinned release of this shell. Header, navigation, standard information pages, footer, shared styling, and common behavior are generated from a stable component API.

Application-owned

  • Primary workflow and content
  • Application CSS and JavaScript
  • Application metadata and security configuration

Shell-owned

  • MarinOS banner and application header
  • About, Security, Accessibility, and Updates framework
  • Footer, feedback control, routing, and shared utilities

The application loads its own CSS after the shell so app-specific rules remain local.

Distribution contract

Run scripts/install.sh to install vendor/marinos/ and synchronize the required local fonts. Do not edit vendored files inside an app.
